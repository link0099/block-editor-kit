# 块式富文本交互规范

## 块、排版和键盘

- 每段正文、标题和列表项各占一块，表格整体是一块。加粗、斜体、下划线和颜色作用于块内选中文本。自动折行与 Shift+Enter 保留在原块。
- Enter 从光标切分内容。正文或标题后新建正文。非空列表项后新建同类同级项，既有子项仍归原项。空列表项按 Enter 转正文。
- 行首输入 `* ` 生成项目符号，输入正整数加 `. ` 生成编号。编号起点随块保存。同级连续项续号，正文、标题、表格或同级项目符号分隔编号序列。
- 列表前有同级或更深列表项时，Tab 将当前项和子项一起缩进，Shift+Tab 退一级。项目符号按实心圆、空心圆、方块循环。编号按数字、小写字母、小写罗马数字循环。
- 光标在列表文字开头按 Backspace 时，子项退一级，顶层项转正文，已有子项一起提升。光标在文字中间照常删字。删除最后一个块后保留可直接输入的空文档。
- 正文段间距为 4px，列表项间距为 2px，小标题上方 14px、下方 4px。工具栏固定在滚动正文上方，图标悬停或聚焦显示提示。

## 光标和拖动

- 空文档首行和占位提示对齐。单击字符将光标放在字符右侧，单击行内空白落在该行末尾，单击文档内容下方落在下一行开头。仅为光标停靠创建的临时空行不写入文档。
- 普通输入和输入法组词用细光标，组词时常亮。三击选择该行文字，文字选区不涂满行尾或空单元格。表格支持跨单元格连续拖选。
- 指针进入文字范围时，左侧距正文 8px 出现六点手柄，行尾留白不触发。拖动显示半透明预览和块间落点线，靠近滚动区边缘可自动滚动。有效落点松手重排，Escape 或拖出取消。

## 表格

- 工具栏插入默认 2 行 3 列的表格。右侧和下方「+」追加列和行，左上「⋯」选择整表并打开菜单，拖动同一控件可移动整表。
- 点击行列手柄打开菜单，移动超过 5px 后进入排序。分隔线横移超过 5px 后实时调整整列，取消时恢复宽度。插入、删除和调整作用于规整的行列，合并单元格保留原布局。
- 标题行和标题列可独立开启，分别固定在滚动区顶部和左侧。开启固定的行、列留在首位。复制保留内容、列宽和标题设置，删除需再次确认。
- 验收时检查空白、长文本折行、编号重排、嵌套列表回读、中文输入法、跨格选区、窄窗口表格滚动和无效拖动取消。

## 撤销和重做

- Windows / Linux：Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做；Mac：⌘Z、⌘⇧Z。工具栏无可用操作时禁用对应按钮。
- 覆盖真实内容变更：输入、删除、粘贴、格式、拆合块、列表缩进、移动块及表格结构、排序和宽度。一次粘贴、一次输入法上屏或一次成功拖动各只记一步；选择、移动光标和取消拖动不记录。
- 每份文档的当前编辑会话最多保留 100 步；撤销后的有效新编辑清空重做分支；无变化不清空。撤销和重做尽量恢复操作前后的选区。不将操作历史写入草稿、文件或云端。
